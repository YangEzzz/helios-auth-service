# 项目统一登录配置

一个项目对应一份统一登录设置。管理接口使用项目 UUID：

- `GET /api/v1/sso/projects/:project_id`：读取项目名称、项目标识、启用状态及全部允许返回地址。
- `POST /api/v1/sso/projects/:project_id`：仅接收 `enabled` 和 `redirect_uris`。后端使用项目标识作为登录 client ID，首次保存生成密钥并仅返回一次。
- `POST /api/v1/sso/projects/:project_id/rotate`：明确确认后更新该项目全部凭据的密钥。

接口仍由管理员角色与 CSRF 校验保护。授权、PKCE、一次性 code 和精确返回地址校验沿用原有流程。

历史本地/线上 client 保留为兼容凭据。读取时汇总、去重返回地址，不写数据库；保存时锁定项目行，在同一事务中创建项目凭据并统一全部旧凭据的返回地址、名称和启用状态，保留旧密钥。只有明确更新项目密钥才令旧密钥失效。无需数据库迁移。

旧的新增 client 和单 client 密钥更新接口返回 410，防止继续新增同项目应用；旧列表接口只保留读取兼容。管理界面不展示应用列表、应用创建或重复身份字段。

验证：后端配置汇总/空态/混合启用状态/CSRF/非法地址测试及编译通过；现有数据库交换集成测试仍需要独立 `HELIOS_SSO_TEST_DSN`，本次未向真实数据库写入测试配置。
